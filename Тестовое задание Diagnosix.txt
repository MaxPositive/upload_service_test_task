Тестовое задание: Diagnosix (фрагмент MVP)

Цель
Реализовать один из микросервисов Diagnosix — auth-service или upload-service (на выбор). Ваша задача — продемонстрировать архитектурное мышление, владение FastAPI, Docker, PostgreSQL и взаимодействием с внешними компонентами (MinIO / JWT).

Вариант 1: Auth-Service

Функции:
Регистрация пользователей (/register)
Аутентификация (/login)
JWT-токены с ролью пользователя (patient, doctor, admin)
Получение информации о пользователе (/me)
Технические требования:
FastAPI
PostgreSQL
Alembic (миграции)
Pydantic модели
JWT (например, с PyJWT или fastapi-jwt-auth)
Вариант 1: Upload-Service

Функции:
Загрузка файла (/upload)
Сохранение в MinIO
Возврат ID и URL файла
Сохранение метаданных в PostgreSQL
Поддерживаемые форматы:
DICOM (.dcm), JPG, PNG, PDF
Технические требования:
FastAPI
MinIO SDK (например, minio Python-библиотека)
PostgreSQL
Хэш-сумма файла или UUID в качестве ID
Общие требования

REST API с OpenAPI-документацией (Swagger)
Docker + Docker Compose (с PostgreSQL и MinIO, если используется)
README.md с инструкцией по запуску
Примеры curl/Postman-запросов
Unit-тесты хотя бы для одного эндпоинта
Критерии оценки

Корректность работы API
Структура проекта и читаемость кода
Безопасность (валидация, JWT, доступ к MinIO)
Уровень тестов
Документация и понятность
